What is LightMem?

LightMem is a local persistent memory engine for AI agents. A Rust CLI, Python SDK, and MCP server let your tools store and retrieve facts, preferences, decisions, and attachments across sessions.

Does it need a cloud service?

The default engine uses local SQLite storage and local ONNX models. Models download on first use; once cached, the local configuration works offline. Ollama is optional and can use a local or remote endpoint.

How do I transfer or back up my memories and videos?

Use lmem bundle export -o backup.zip to package the SQLite database, all attached videos, images, and documents, and vector embeddings into a single compressed .zip file. On your new machine, run lmem bundle import backup.zip to restore everything in milliseconds without re-computing embeddings.

Can different agents share memory?

Yes. Register your agent connections against the same user and project, then select the scope each tool should use. See the integration guide → for setup.

How do I get started?

Install with pip install -U lmem using Python 3.8 or newer. Native wheels are available for supported platforms; shell installers and source builds are also documented in the quick start →.
