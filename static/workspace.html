    NO GUESSING

    Your effective workspace.

    To use another configuration root or an arbitrary database, restart with LIGHTMEM_CONFIG_DIR=… lmem --db … ui. This workspace manages local vaults; remote CLI capabilities are documented separately.

    No analytics, third-party assets, or external font requests are used in this workspace. Only configured model services and explicit downloads need network access.

    Configuration precedence

    Explicit CLI database selection takes precedence over environment and automatic project/global selection. A named connection selects its own scope and cannot be combined with a database override. Environment API keys can supply credentials even when a stored key is cleared.

    Model/provider choices shown here are this server’s active settings. Restart the workspace after changing configuration externally.
